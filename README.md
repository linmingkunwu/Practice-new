# NewRepo

Visual Studio C# 项目。

## 环境要求

- Windows 10/11
- [Visual Studio 2022](https://visualstudio.microsoft.com/zh-hans/downloads/)
- .NET SDK

## 快速开始

1. 克隆仓库
   ```bash
   git clone https://github.com/linmingkunwu/NewRepo.git
   ```

2. 用 Visual Studio 打开解决方案文件 (`.sln`)

3. 按 `F5` 编译运行

## 项目结构

```
NewRepo/
├── .gitattributes    # Git 行尾规范化配置
├── .gitignore        # Git 忽略规则（Visual Studio 模板）
└── README.md         # 项目说明
```
