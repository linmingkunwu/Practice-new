第 1 章 条码概述

教材 P1~26
1.1

起源、发展、特点

名解 / 简答

发展里程碑（P1~3）

1949 乔·伍德兰德/贝尼·西尔佛“公牛眼”条码专利 → 1970 美国 UPC → 1973 UCC 建立 UPC 应用系统 → 1974 Intermec 推出 39 码 → 1977 欧洲 EAN（与 UPC-A 兼容）→ 1988 中国物品编码中心成立 → 1991 中国加入 EAN → 2005 GS1。条码被称为“计算机文化”“商品进入国际市场的身份证”。

条码技术特点（P3~5）

简单、采集速度快、采集信息量大、可靠性高、灵活实用、自由度大、设备结构简单/成本低。二维条码优点：信息容量大、编码范围广、保密防伪好、译码可靠性高、修正错误能力强、容易制作且成本低、形状可变。

条码技术研究内容（P6）

条码编码技术、条码生成与印制、条码识读、条码检测、条码应用系统（编码→载体→识读→应用）。

一维码 vs 二维码（P4~5）

一维码只在一条方向表示信息，信息量有限、依赖数据库；二维码高密度、大容量、可编码图片/指纹等，纠错强（破损 ≤50% 仍可还原），误码率 ≤0.00001%。

1.3

条码体系、符号结构与物品标识

结构 / 名解

物品编码技术体系（P10~12）

物品编码技术体系 = 物品编码标准体系 + 物品标识技术 + 物品编码应用系统；先给物品编唯一代码，再用条码/RFID 等载体标识、采集、共享。

条码符号结构（P14~16）

一维条码：左侧空白区（静区）→ 起始符 → 数据符 → 校验符 → 终止符 → 右侧空白区；EAN/UPC 还有中间分隔符。二维条码：寻像图形、定位图形、数据区、纠错区等。

条码编码理论：用条/空的宽度组合表示数字或字符；一维码靠校验码检错，二维码靠纠错算法（如 PDF417 用所罗门算法）还原局部破损信息（P18~19）。

GS1 概述、框架与特点

名解 / 简答

GS1 是什么（P33~35）

全球统一标识系统：编码体系 + 数据载体体系 + 数据共享体系。前身：1973 UCC（UPC）、1977 EAN；2005 年 EAN International 与 UCC 合并成立 GS1。目标是全球贸易数据可追溯（track/trace/防伪/可信/谱系/退货/下架/召回）。

GS1 标准体系特点（P35~36）

系统性、科学性、全球统一性、可扩展性（教材列 4 点）：完整编码体系、不同对象不同结构、全球事实标准、随信息技术发展不断完善。

3.1~3.4

代码、编码、设计原则与方法

名解 / 简答

代码与编码（P59~62）

代码：用数字、字母或符号表示事物/概念的符号。作用：标识、分类、排序、统计、检索、沟通，便于计算机处理。编码：给对象赋予代码的过程；要选择对象、确定分类方法、设计代码结构、校验。

代码设计原则（P62~63）

唯一性、合理性、可扩充性、简明性、适用性、规范性（教材表述；GB/T 7027 还提科学性、系统性、可扩延性、兼容性、综合实用性）。

分类方法（P63~65）

线分类法：层级/树状，大类—中类—小类（行政区划代码）。面分类法：按多个“面”（属性）组合（服装按性别/年龄/款式）。两者结合为混合分类法。

代码种类（P65~66）

顺序码（递增，简单不便分类）、层次码/区间码（分段表层级）、矩阵码（行列坐标）、特征组合码（各面组合）、复合码（两种以上组合）。

3.5

代码的校验：教材用“余数”作校验位

计算题 · 与商品条码不同

五步法（P65~66）

① 每一位 Cᵢ 定权数 Pᵢ（算术级数、几何级数或质数）；② 求加权和 S=ΣCᵢPᵢ；③ 确定模数 M；④ 求余数 R=S mod M；⑤ 校验位 = R（余数本身），不是 M−R。

教材例（P66）

原码 32456，权数 7,6,5,4,3：S = 3×7+2×6+4×5+5×4+6×3 = 91；M=11；R=91 mod 11=3；校验位=3 → 324563。

必考区别：商品条码校验位 C = (10 − S mod 10) mod 10；教材“代码校验”C = S mod M。余数为 10 时按教材规定处理（常见用 X）。

4.1

术语、编制原则、代码结构

名解 / 简答

关键术语（P73）

零售商品：零售业中按预先定义特征定价/订购/结算的产品或服务。零售商品代码：标识商品身份的唯一代码，全球唯一。前缀码：前 2 或 3 位，由 GS1 分配。

编制原则（P73）

唯一性（相同商品同码、不同商品不同码）
无含义性（商品项目代码不表示特定信息）
稳定性（基本特征不变则代码不变）

三种代码结构（P73~74）

13 位（EAN-13）
12 位（UPC-A）
8 位（EAN-8）
分别适应不同情形。

码制结构适用 / 注意
EAN-13（4 种结构）厂商识别代码 7~10 位 + 商品项目代码 5~2 位 + 校验码 1 位；厂商识别代码前 3 位为前缀码，中国 690~699我国零售商品最常用；不同企业按规模选 7/8/9/10 位厂商代码
UPC-A（12 位）系统码 1 + 厂商代码 5 + 商品代码 5 + 校验 1北美零售；等于前置码为 0 的 EAN-13
EAN-8（8 位）前缀码 + 商品项目代码 + 校验码 1小包装；不是压缩码
例题：EAN-13 数据位 692900013579 的校验码：从右往左偶数位求和×3 + 奇数位求和 = (9+9+0+1+5+9)×3 + (6+2+0+0+3+7) = 99+18 = 117 → 10−7 = 3 → 6929000135793。

EAN-13 / EAN-8 / UPC-A 的条码表示

结构 / 图示题

EAN-13 符号（P76~84）

95 个模块：左空白区 + 起始符 101 + 左侧 6 位（A/B 子集，奇偶由首位决定）+ 中间分隔符 01010 + 右侧 6 位（C 子集）+ 终止符 101 + 右空白区。左侧空白 ≥11X，右侧 ≥7X；放大系数 0.80~2.00。

EAN-8 符号（P102~103）

67 个模块：起始符 101 + 左侧 4 位（A 子集）+ 中间分隔符 01010 + 右侧 4 位（C 子集）+ 终止符 101；左右空白区各 7 个模块；用于小包装。

UPC-A 符号（P104~105）

与 EAN-13 同为 95 个模块，左右空白区各 9 个模块；二进制表示同前置码为 0 的 EAN-13；系统码 0/1 常规零售。

EAN-13 首位与左侧奇偶：首位不直接画成条空，而用左 6 位的 A/B（奇/偶）排列表示；右侧固定 C 子集。0→AAAAAA，1→AABABB……（详见速查卡）。

4.3

变量贸易项目代码（店内条码）

计算 / 结构

基本概念（P87~88）

店内条码：前缀码为 20~24 的商品条码，用于商店自行加工店内销售的商品和变量零售商品。8 位店内条码前缀为 2。变量零售商品：无法预先确定销售单元，按基本计量单位计价销售的商品。

条码选择（P91）

13 位代码 → EAN-13 条码；8 位代码 → EAN-8 条码。由商店自行编制，不进全国商品数据库。

4.4

特殊情况下的编码

简答 / 案例

产品变体 / 组合包装

产品变体：颜色、规格、包装等不同 → 不同商品项目代码（不同 GTIN）。
组合包装：多个单品组合 → 分配新 GTIN；也可用 AI(02) 内容物 GTIN + AI(30) 数量。

促销品 / 重新启用

促销品：临时组合/赠品 → 临时 GTIN，促销结束不复用。
重新启用：停用后按规定间隔才可复用，不能随意。

4.5~4.6

符号放置与零售端 POS 应用

简答

条码符号放置（P96~100）

印在包装主显示面平整处；避开接缝、封口、折边、弯曲、透明/反光区域；保证左右空白区；条高方向与扫描方向匹配；曲面/小包装选 EAN-8 等短码；遵循 GB 12904 与教材图示。

零售端 POS（P100~107）

POS 功能：收银结算、价格查询、库存扣减、销售报表、会员/促销；单品管理：条码为索引关联“单品—价格—库存—供应商”；支撑连锁经营、补货、质量追溯、经营分析。

补充：UPC-E 是 UPC-A 的消零压缩（系统码 0/1，8 位 = 1+6+1，校验码抄 UPC-A）；本科书 4.2 只列 EAN-13/EAN-8/UPC-A，若老师补充了 UPC-E，用速查卡/练习器那套规则。
课后题（P107）：商品标识代码/条码符号；690/692 含义；EAN-13 结构选择原则；印制注意；校验码计算。

第 5 章 储运包装条码应用

教材 P108~124
5.1

术语与 14 位代码结构

名解 / 计算

关键术语（P109）

储运包装商品：由一个或若干个零售商品组成的用于订货、批发、配送及仓储等活动的包装商品。
定量储运包装商品：由定量零售商品组成、规格稳定的储运包装商品。
变量储运包装商品：由变量零售商品组成的储运包装商品。

14 位代码结构（P109~110）

包装指示符 1 位 + 内部所含零售商品代码前 12 位 + 校验码 1 位。
包装指示符：1~8 定量储运包装商品，9 变量储运包装商品。
13 位储运包装代码与 13 位零售代码结构相同。

14 位代码校验（P110 表5-2）：自右向左编号（校验码为 1 号）；偶数位求和 ×3；奇数位求和；相加；10 减个位（个位 0 则校验位 0）。例 0690123456789C：偶数位和×3 + 奇数位和 = 102+26=128 → 10−8=2 → 06901234567892。
5.2~5.3

编码方案与条码选择

简答 / 选择

单个包装的非零售商品

独立包装但不经 POS 结算（冰箱、洗衣机等）：可用 GTIN-13 或 GTIN-14。

多个相同/不同包装等级

多个相同零售商品组成不同包装等级：用 GTIN-14（在原 GTIN-13 去校验前加包装指示符，重算校验）。不同零售商品标准组合：用与各单品都不同的新 13 位代码。

变量非零售商品

按基本计量单位计价、数量随机（如待分割猪肉）：用 GTIN-14，包装指示符 9；可配 AI(310n) 重量。

条码选择：13 位 → EAN-13；14 位 → ITF-14；需要附加信息（批号/日期/数量等）→ GS1-128（教材称 EAN-128）。
5.4

ITF-14、25 码、交叉 25 码

特点 / 选择

25 码

每个字符用 5 个单元（条/空）表示，其中 2 个宽单元；只能表示数字；密度较低。

交叉 25 码

两位数字“交叉”编码：奇数位用条、偶数位用空，密度高；只能数字；ITF-14 是其典型应用。

ITF-14 特点（P112~114）

14 位、交叉 25 条码；印刷需加保护条（bearer bar）；对瓦楞纸箱印刷误差容忍度高；适合直接印在纸箱上。

放置与仓库应用（P118~124）：箱码印在包装箱指定面/相邻面，避开接缝和封箱带，留足空白区；仓库作业：订货→收货→入库→摆货→补货→盘点→出库，条码采集实现实时库存、先进先出、批次追溯。
课后题（P124）：14 位代码包装指示符含义；何时选 13/14/128 位编码；ITF-14 特点与场合；储运条码印制位置与包装物关系。
★

14 位代码示例 + ITF-14 要点

计算 / 选择

例：0690123456789C

自右编号，偶数位和 = 9+7+5+3+1+9=34，×3=102；奇数位和 = 8+6+4+2+0+6=26；合计 128；10−8=2 → C=2，代码 06901234567892。

ITF-14 关键点

交叉 25 条码，14 位数字；必须有保护条（bearer bar）；适合瓦楞纸箱直接印刷；放大系数/尺寸按 GB/T 16830；通常印在箱的指定面。

包装指示符：1~8 用于定量储运包装（不同包装级别可分配不同指示符）；9 用于变量储运包装（如按重量计价的整箱商品）。指示符不是校验位。
本章必背：储运包装术语 · 14 位结构（1+12+1）· 指示符 1~8 定量/9 变量 · 14 位校验 · ITF-14/交叉25/保护条 · 条码选择 · 仓库流程。ch1-6 notes p.6

第 6 章 物流单元条码应用

教材 P125~192
6.1

物流单元与单元化技术

名解 / 简答

物流单元（P125）

在供应链过程中为运输、仓储、配送等建立的包装单元；为便于运输和仓储而建立的任何组合包装单元（一箱不同颜色/尺寸的服装、一个含 40 箱饮料的托盘等），需对其进行个体跟踪与管理。

单元化技术（P126~128）

把单件/散装物品组合成尺寸规格相同、重量相近的标准“单元”，再组合成更大集装单元；三大类：集装箱系列、托盘系列、周转箱系列。优点：装卸合理化、缩短装卸时间、降低劳动强度、提高效率、便于机械化。

6.2~6.4

SSCC、附加信息 AI、GLN

结构 / 计算

SSCC-18（P129~130）

扩展位 1 位 + 厂商识别代码 7~10 位 + 系列号 9~6 位 + 校验码 1 位，共 18 位，4 种结构；用 AI(00) 表示；扩展位 0~9，由厂商分配，可区分不同生产厂/车间。

附加信息代码（P130~136）

由 AI + 编码数据组成，需与 SSCC 一起处理。常用 AI：02 物流单元内贸易项目 GTIN、33nn/34nn/35nn/36nn 物流量度、401 托运代码、402 装运标识、403 路径代码、410 交货地 GLN、413 最终目的地 GLN、420/421 邮政编码。

GLN（P136~137）：13 位 = 厂商识别代码 7~9 + 位置参考 + 校验；用 AI 410~417 表示参与方/位置，414 = 物理位置；用于物流起点、目的地、发货人、收货人等。
6.5~6.6

GS1-128 符号结构与物流标签

结构 / 标签

GS1-128（P138~160）

基于 Code 128，是 GS1 标准体系物流单元的强制性数据载体。符号结构（左→右）：左侧空白区 + 双字符起始符（Start A/B/C + FNC1）+ 数据字符（AI+数据）+ 校验符 + 终止符 + 右侧空白区。字符集 A/B/C；固定长度 AI 后直接接数据，可变长度 AI 后用 FNC1 分隔。

物流标签（P186~190）

物流标签将若干信息段组合：承运人信息、客户信息、物流单元编码（SSCC）、附加信息（GTIN、批号、日期、数量等）；一般含 GS1-128 条码；标签尺寸/格式/技术要求按 GB/T 18127 与教材；条码符号应位于标签最下端，人读字符高度 ≥3mm。

标签放置（P190~192）：物流单元直立面放置；推荐两个相同标签放在相邻两面；托盘包装条码下边缘宜在底部以上 400~800 mm，距直立边 ≥50 mm；箱包装条码下边缘宜在底部以上 32 mm，距边 ≥19 mm；新标签不能覆盖已有 EAN-13/UPC-A/ITF-14/GS1-128 条码。
课后题（P192）：物流单元化含义/作用；物流单元编码规则；常用 AI；物流标签信息组合举例。
