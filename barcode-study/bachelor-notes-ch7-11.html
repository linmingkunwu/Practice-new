第 7 章 制造业生产线上的条码应用

教材 P193~233
7.1

内部物流、个性化定制、柔性制造

名解 / 简答

生产物流（P193）

企业在生产工艺中的物流活动：原材料、零部件、半成品按工艺流程依次流过，最终成为成品送入成品库暂存。它是企业物流的核心部分，与生产工艺伴生。

个性化定制（P194~196）

以需求为中心、多品种小批量；JIT/零库存；物料、半成品、成品最短时间通过各环节直达客户。案例：海尔（中心城市 8h、区域 24h、全国 4 天配送）、IBM 个性化定制。

柔性制造 FMS（P197~199）

由数控加工设备、物料运储装置、计算机控制系统组成的自动化制造系统；能按制造任务/生产环境变化迅速调整，适合多品种中小批量。柔性包括机器、工艺、产品、生产能力柔性；核心还有供应链的敏捷反应。

产品追溯与缺陷召回（P196、P207）

在各生产线上线工位用针式/激光打标二维码，关键工位扫描，经 PLC 等写入数据库；按批次/工序关联生产时间、批号、质检、原辅料信息，实现正向追踪 + 反向溯源。缺陷召回靠 MES（制造执行系统）按条码批次定位问题范围。

MES（P199）

制造执行系统：用条码/PDA/PLC/传感器/RFID/LED 看板等，对原材料上线到成品入库实时采集、控制和监控；上接 ERP 的工单/BOM/库存，下接控制层，实时反馈生产/质量/设备状态。

第 8 章 GS1 与供应链管理

教材 P234~280
8.1

供应链与供应链管理

名词解释高频

供应链（P234）

供应链是一个业务过程：用一条链连接制造商、零售商及供应商，实现产品或服务的制造、传输，目标是通过多个组织间业务处理的合作，把产品从生产线顺利送到消费者手中。

供应链管理 SCM（P234~235）

订单生成、订单执行、订单完成、产品/服务/信息分发过程的合作；供应链内相互依赖形成“扩展的企业”；原材料供应商、流通渠道伙伴、消费者都是主要角色。

push 模式 vs pull 模式（P239~242）

push（推动式）：以制造商为核心，按预测生产后逐级推向市场。
pull（拉动式/需求驱动）：以消费者需求为起点，零售 POS 数据→配送仓库→制造商→供应商，按需补货/生产。
pull 的 4 步：迅速准确获得需求 → 以最低成本满足需求 → 沿供应链做决策 → 把成品送到消费者并收款。

现代供应链 7 个基本特征（P242~243）

增值性、竞争性、复杂性、动态性、市场性、交叉性、面向用户需求。现代供应链是网链结构，由客户需求拉动，具有物流、商流、信息流、资金流 4 种表现形态。

8.2

GS1 在供应链中的四个作用（P244~245）

简答
作用要点
信息编码标准化零售终端：EAN/UPC-13；储运/包装：EAN/UPC-13、EAN-14；物流：SSCC、位置码（GLN）、应用标识符（AI）；制造：店内码。
信息采集自动化条码采集器（一维/二维）、RFID 电子标签、传感器；在零售、配送、运输、生产线各环节自动实时采集。
信息共享实时化标准信息格式 + 标准通信协议（ebXML、GDS），供应链各环节数据快速传递共享，实现业务协同。
供应链物流管理包装、运输、仓储、加工、配送全过程；条码解决数据录入/采集“瓶颈”，支撑物料、生产、仓库、销售、售后、质量管理。
8.3

QR 快速反应与 ECR 有效客户响应

名解 + 简答

QR（P248~250）

QR（quick response，快速反应）：零售商与供应商共享销售信息，缩短补货周期、降低库存。成功 5 条件：改变经营方式/意识；开发应用现代信息处理技术（条码、POS、EOS、EDI、电子支付、VMI、CRP）；建立战略伙伴关系；改变商业信息保密做法、共享信息；供应商缩短生产周期、降低库存。

ECR（P250~251）

ECR（efficient consumer response，有效客户响应）：以消费者为中心，生产商、批发商、零售商协作，利用信息技术提高商品供应效率、降低供应链成本。四要素：高效产品引进、高效商品存储、有效促销、高效补货。

8.4~8.5

GDSN 与供应链协同商务

名解 / 流程

GDSN（P253~254）

全球数据同步网络：数据池 + 全球注册中心基于互联网组成；贸易伙伴通过数据池发布/订阅主数据（GTIN、属性、包装等），保证数据一致。流程：制造商→数据池→全球注册中心；零售商通过数据池查询/订阅；供应商和零售商不能直接连全球注册中心，必须通过数据池接入。

供应链协同商务（P255~258）

两个或两个以上企业为满足目标市场需求，通过协议/联合组织结成的网络式、以销定产的供求模式。参与主体：上下游企业（原料供应商到零售商）、第三方物流、区域平台/中央平台；协同信息分概要信息（品名/数量/重量）和详细信息（价格/折扣等）。

案例：Liverpool（墨西哥零售商）用 EPC/RFID 提升供应链；南京微创 GS1/UDI（医疗器械唯一标识）。

第 9 章 GS1 与物联网应用

教材 P282~315
9.1

物联网定义、应用与三种模式

名解 / 简答

物联网定义（P282）

通过 RFID、红外感应器、GPS、激光扫描器等信息传感设备，按约定协议把任何物品与互联网连接，进行信息交换和通信，实现智能化识别、定位、跟踪、监控和管理的网络。狭义：物到物；广义：信息空间与物理空间融合。

“物”的条件（P282~283）

要有信息接收器、数据传输通路、存储功能、CPU、操作系统、应用程序、数据发送器、遵循通信协议、在世界网络中有可被识别的唯一编号（重点）。

三种应用模式（P286）

① 对象的智能标签（NFC/二维码/RFID 标识对象）；② 环境监控和对象跟踪（传感器网络/GPS/摄像头）；③ 对象的智能控制（根据数据决策、改变对象行为）。

物联网 vs 互联网（P283~284）

物联网核心和基础仍是互联网，是互联网的延伸扩展；用户端延伸到物与物之间。解决 T2T（物对物）、H2T（人对物）、H2H（人对人）互联；M2M（机对机）。

9.2

EPC、RFID、GDS：物联网三大技术

名解 + 原理

EPC（P287~290）

电子产品代码，对供应链对象（物品、货箱、货盘、位置等）全球唯一标识，存放在 RFID 标签上；针对单品，是 GTIN 的扩充。5 种编码体系：SGTIN、SGLN、SSCC、GRAI、GIAI。96 位 EPC 结构：标头 + 厂商识别代码 + 对象分类代码 + 序列号。特性：科学性、兼容性、全面性、合理性、国际性、无歧视性；原则：唯一性、简单性、可扩展性、保密与安全性。

RFID（P290~292）

射频识别，非接触自动识别。组成：标签（耦合元件+芯片）、阅读器、天线。原理：阅读器发射射频信号→标签感应取电→发送自身编码→阅读器接收/解调/解码→后台处理。特点：非接触、可识别高速运动物体、可同时识别多个标签、适应恶劣环境。

GDS / GDSN（P293~296）

全球数据同步：利用计算机网络保持供应链贸易伙伴信息一致。GDSN = 全球注册中心 + 多个数据池；制造商向数据池发布贸易项信息，数据池向注册中心注册基本信息；零售商通过数据池查询/订阅。GDSN 关键特性：通过数据池接入；商品条目用 GTIN + GLN + 目标市场 唯一标识；企业用 GLN 标识。

EPC 与条码的关系

EPC 编码以 RFID 为载体，实现自动采集；EPC 与 GTIN 兼容，GTIN、SSCC、GLN 等可转换到 EPC；EPC 是“钥匙”，产品信息保存在 EPCglobal 网络/EPCIS 中。

9.3

物联网标识体系与 Ecode（P296~301）

概念 / 结构
Ecode：我国物联网统一标识；由 版本 V、编码体系标识 NSI、主码 MD 等组成，最大总长度 256 位；有二进制、十进制、字母数字型、Unicode 等类型；V 和 NSI 决定 MD 的结构和长度。Ecode 可存储在一维条码、二维条码、射频标签、NFC 标签中，并有统一的注册与管理规则。
9.4~9.6

物联网数据、处理模型与应用

简答 / 选择

数据 6 特点（P301~302）

数据量大、类型复杂、异构性、高度动态性、时空特性、不完整性。

数据处理模型 4 层（P302~305）

感知控制层（传感器/RFID/单片机采集）→ 网络层（无线传感网/现场总线/公网专网传输）→ 平台服务层（存储、建模、挖掘、云计算/大数据）→ 应用服务层（C/S、B/S、M2M、云计算等）。

应用场景（P308~313）：智能家居、远程医疗、老人关怀、药品安全监控、零售/物流/供应链、食品追踪、农业育种；国家物联网标识管理与公共服务平台（P313）。
课后题（P315）：物联网与互联网区别联系；EPC 编码原理；RFID 在物联网中的应用；Ecode 如何统一不同编码体系；以食品安全追溯为例说明 Ecode 应用。

第 10 章 GS1 与电子商务

教材 P316~350
10.1

电子商务中的条码应用

简答 / 案例

源数据与两码（P316~319）

源数据：以商品条码为关键字，由生产厂商自主提供的商品生产源头数据，来源可靠、真实、质量高。中国物品编码中心 + 阿里巴巴推动 GS1 标准、商品源数据、扫码购物。两码：组织机构代码（企业信用/实名）+ 商品条码（产品追溯），用于电商信用与质量追溯。

条码在电商中的作用（P318）

统一编码身份标识，线上线下一致；商品、包装箱、仓库、订单、参与方可用商品条码/GLN/箱码标识；支撑电商物流自动化、可视化；构筑可信交易平台、产品追溯。

10.2

GS1 DataMatrix 与汉信码

选择 / 特点

GS1 DataMatrix（P320~327）

矩阵式二维条码；GS1 采用其 ECC 200 标准版（ISO/IEC 16022）；有 “L” 形寻像图形，Reed-Solomon 纠错；可编码 GS1 数据结构（FNC1），码制标识符 ]d2；适合小件、DPM 直接部件标印、医疗等；需二维成像式识读器。

汉信码（P327~333）

我国自主知识产权二维码，GB/T 21049—2007；特点：专利免费、汉字编码能力强（支持 GB 18030）、抗污损/抗畸变、识读速度快；应用：图书、移动商务、信息安全、产品追溯、增值税发票等。

矩阵式二维条码：在矩形空间用黑白像素点阵编码（点出现=1，不出现=0）；常见 Data Matrix、QR Code、汉信码。QR Code 由 Denso-Wave 1994 年发明，开放授权，是手机二维码主流。
10.3~10.4

二维码入口与 O2O 模式

名解 / 简答

二维码入口（P333~336）

从域名、搜索引擎到 APP/二维码；二维码用于 APP 下载、标签类业务（拍码溯源/互动）、凭证类业务（电子票/优惠券）。

O2O（P338~343）

Online to Offline：线上筛选/下单/结算，线下消费/服务；参与者：商家、消费者、O2O 平台；特征：本地化、社会化、服务化；二维码用于营销宣传、支付、凭证/入口。

O2O 瓶颈与改进（P343~345）

瓶颈：客户认知度、终端问题、编码标准、安全问题、平台自身问题；改进：营销宣传、普及终端、统一编码、行业监管。

10.5~10.6

二维码支付与快递跟踪

案例 / 简答

二维码支付（P345~347）

基于账户体系的无线支付：商家把账号、价格等生成二维码；用户扫码完成支付结算。案例：建行“龙支付”（钱包/二维码/全卡付/云闪付等）。问题：恶意网址/病毒、信息泄露、监管与安全标准。

快递跟踪（P347~349）

快递员配备无线手持终端“巴枪”，每个环节扫描快件条码，系统/消费者可实时跟踪；车辆装 GPS，分拣中心实时监控；RFID 可批量读取包裹，标签可改写、可转发。

第 11 章 条码技术的未来发展与应用趋势

教材 P351~372
11.1

市场状况与应用层次

选择 / 简答

三类识读设备（P351~354）

① 手持式条码扫描器（需求量最大；激光/线性影像/面阵影像，面阵影像增长最快）；② 固定式 POS 扫描器（大型双窗/立式/小型桌式）；③ 固定式工业类扫描器（增长最快；工业激光 vs 工业影像）。

应用三阶段（P354）

第一阶段：自动结算；第二阶段：企业内部管理；第三阶段：电子商务、物联网、全球数据同步。我国处于第二阶段向第三阶段过渡。

11.2

主要应用领域

简答 / 举例

零售/物流/仓储

POS 结算、库存管理、分拣配送；手持/固定式扫描器。

产品溯源

农产品/食品/医药质量溯源；条码成本低、操作便捷、信息量大。

工业制造

《中国制造 2025》；物料调配、零件识别分拣、动态生产控制、检测追踪；机器视觉。

医疗健康

药品、标本、设备、医护人员、病人身份标识；HIS/CIS 信息交互。

O2O 运营

二维码连接线上线下；扫码支付、营销、凭证；影像式扫描器需求增长。

其他

火车票、机场、彩票、税务、现场服务等。

11.3

未来趋势（P360~364）

简答
四个趋势：① 影像扫描设备逐步取代激光扫描设备（拍照式捕获整码、抗强光、无机械结构、耐摔、可读屏幕码）；② 条码与 RFID 等其他自动识别技术融合；③ 亚太市场成为前沿；④ 物联网成为推动条码设备发展的主要动力（条码识读设备属于感知层）。
11.4

三维条码（P364~366）

名解 / 特点

概念与特点

三维条码（3D Barcode/多维条码/万维条码）：在二维条码基础上增加颜色、灰度、层厚等维度；信息容量更大，可表示图像/音频/视频等；防伪性强。2014 年中国三维码问世，具有自主知识产权。

缺点与应用

缺点：对破损/色差敏感，一个像素损坏或色差可能导致信息丢失/无法读取。
应用：证、章、卡、照、物品追踪、防伪溯源、智慧城市等。

11.5

工业 4.0 与条码技术（P366~372）

简答 / 案例

工业 4.0 要点

2011 年汉诺威工业博览会提出；德国《高技术战略 2020》十大未来项目之一；核心：CPS（信息物理系统），软件、传感器、通信系统集成；两大主题：智能工厂、智能生产；三大主题（含智能物流）；关键技术：ICT、M2M、大数据、与 ERP/PLM/SCM 联动。

条码/二维码/RFID 的作用

产品标识与跟踪：条码/二维码低成本、高可靠、易用（DPM 直接零部件标刻）；用于 ERP、MES、SCADA；固定式工业扫描器自动读取；Kiva 机器人扫描地面条码搬运货架；UHF RFID 识别距离远、速度快、可批量、适应恶劣环境。

名词

高频名词解释（按“定义 + 组成/特点 + 作用”答）

开卷直接抄

生产物流 / FMS

生产物流：企业在生产工艺中的物流活动。FMS：数控设备+物料运储+计算机控制，能迅速调整、适合多品种中小批量的自动化制造系统。

供应链 / SCM

供应链：连接供应商—制造商—零售商—消费者的业务过程。SCM：订单生成/执行/完成及产品/服务/信息分发过程的合作。

QR / ECR

QR：快速反应，共享销售信息、缩短补货周期。ECR：有效客户响应，以消费者为中心，供应链协作降本增效。

GDSN / 协同商务

GDSN：数据池+全球注册中心，主数据同步。协同商务：企业间共享信息、协同计划与执行。

物联网 / EPC / RFID

物联网：物品与互联网连接，实现识别/定位/跟踪/监控/管理。EPC：单品唯一电子代码。RFID：射频非接触自动识别。

Ecode / 三维条码

Ecode：我国物联网统一标识（V+NSI+MD，≤256 位）。三维条码：在二维基础上加颜色/灰度/层厚等维度，容量大、防伪强。
